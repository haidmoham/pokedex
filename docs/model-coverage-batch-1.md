# Model coverage batch 1

The initial exact-geometry pass admitted no new models. The 14 previous budget failures were processed again with one worker, a 120-second per-model timeout, hash-matched sources, and unchanged admission limits. Exact decoded geometry comparisons passed. Eight still exceeded the 750 KB transfer limit even at 256px WebP textures (1.38–5.06 MB); six exceeded structural complexity limits. Texture deduplication and pruning did not resolve those six. That initial pass used no mesh simplification, position quantization, or budget relaxation.

The optional `--texture-size 256` profile writes separate artifacts and reports, leaving the default 512px profile intact. These candidate files remain outside runtime admission. Passing machine checks would still require approval of the exact candidate pose hash; an animation name alone cannot establish a usable pose.

All 54 regular-species model URLs advertised by the upstream optimized catalog returned HTTP 404 in a two-worker HEAD check. The fork inspected has the same asset tree. Other inspected repositories provide older FBX/DAE or proprietary Clip Studio formats and do not establish usable source asset permissions.

The seven explicitly restricted-license sources remain excluded. Zubat's current public page confirms a NonCommercial license. The other six public pages returned HTTP 403; their embedded claims are recorded without asserting current independent verification. Another 427 source assets lack per-asset provenance or usable terms. The upstream mapping file is empty. Repository MIT licensing and uploader licenses do not establish underlying Pokémon rights.

Exact per-asset source URLs, original and candidate SHA-256 hashes, byte counts, processing failures, all missing URL responses, and source research findings are in [the batch manifest](../content/models/coverage-batch-budget-2026-10-01.json). This is a separate branch from Shuffle so it can be reviewed independently. Existing pose guards reject the four verified bad assets and preserve artwork fallback. Full 1025-species model coverage has not been reached.

## Reviewed lossy follow-up

Ten models now pass machine admission and individual mobile pose review: Weezing, Magnezone, Froslass, Pancham, Tsareena, Pheromosa, Zamazenta (shield form), Floragato, Quaxwell and Scream Tail. Effective runtime coverage rises from 517 to 527 species. Their 73–481 KB local derivatives are included in this branch.

The opt-in profile welds vertices, targets 20% retained vertices with a 2% radius error cap and locked borders, quantizes positions/normals/UVs, and uses 256px WebP textures. Later candidates remove auxiliary PBR maps and join compatible static meshes. Pancham uses a gentler 50% target and 0.5% error cap after the first render lost eye detail. Pheromosa receives a 180-degree root rotation to face forward. These percentages are processing parameters, not claimed visual-quality scores. No admission budgets were relaxed.

Future bounded runs can use `node scripts/model-pipeline/optimize.mjs --ids 674 --texture-size 256 --geometry-profile review-gentle`. `review-lossy` selects the stronger profile; `--facing-rotation 180` adjusts a confirmed backwards-facing candidate. Each profile writes a separate artifact and report. These commands produce review candidates, not admitted runtime assets. Approved hash-bound proposals are admitted with `node scripts/model-pipeline/admit.mjs --reviewed content/models/reviewed-batch-2026-10-01.json`.

Xurkitree, Magearna, Stakataka and Runerigus remain rejected after actual rendering. Xurkitree and Runerigus have collapsed or disassembled source poses, Magearna has outstretched rest-pose arms and remains structurally over budget, and Stakataka's cuboid biped does not provide a usable recognizable species view. Original and alternate-angle renders were inspected where relevant. No usable idle was present in these candidates.

[The lossy manifest](../content/models/coverage-batch-lossy-2026-10-01.json) identifies every exact profile, output hash, source hash and pose decision. [Reviewed proposals](../content/models/reviewed-batch-2026-10-01.json) and [admission results](../content/models/admission-batch-2026-10-01.json) bind approved screenshots to the exact admitted bytes. Screenshots are in [the review folder](model-review-2026-10-01).

The original unoptimized catalog's 54 missing URLs also return 404. Public Sketchfab searches were performed for all 54 names: 39 have title-matching leads, eight return only unrelated-title hits, and seven return no results. Searches are not exhaustive proof that no model exists. [Search results](../content/models/alternative-source-search-2026-10-01.json) and [individual source-page verification](../content/models/source-page-verification-2026-10-01.json) distinguish model leads, license observations, download availability and access blockers. No authenticated downloads, new credentials or permission bypasses were used. The primary repository contains no original GLB directory and its mapping file remains empty. Two additional Cobblemon asset repositories have no visible license/credit metadata in their trees; their public availability does not grant asset permissions.

Seven inspected missing-species leads display CC Attribution links, and all seven actual download dialogs require login. Two are accessory/crossover leads (a Brute Bonnet mask and a Goat Simulator Scovillain), so even authorized bytes would still need full-depiction and render review. The other inspected matching leads do not advertise a public download; none is treated as an admissible source. Six of the seven previously restricted cases now have their NC/NC-SA/NC-ND license links independently reconfirmed in the browser; Grovyle's page has no visible Creative Commons license link and remains excluded. The remaining 427 provenance gaps cannot be resolved by assigning terms from unrelated uploads.

## Recursive provenance audit

All 427 files with missing uploader terms were fetched from their existing public source URLs and matched to their previously recorded SHA-256 hashes. A recursive scan of the entire GLB JSON, beyond `asset.extras`, found no license, author, source or copyright fields and no Sketchfab or Creative Commons URLs in any of them. This audit used one worker, a 16 MiB per-file limit, a 150 MiB total limit and a three-minute run cap. No source bytes were admitted, and missing metadata is not interpreted as permission. [The exact per-file evidence](../content/models/deep-provenance-audit-2026-10-01.json) records each URL, hash, size, exporter and outcome.

The approved Shuffle slice was separately fast-forwarded to main at `7a7af58f422bbcb5f936963b88f8f7dc9bde0317`. Both existing public mirrors were verified at that revision, including actual gesture/history behavior. This model branch remains independent and its ten new admissions are not part of that production landing.

All 115 existing tests pass after updating admission evidence checks for individually reviewed lossy derivatives. The production build passes with the existing large-bundle warning. Browser checks verified actual-app model loading, Pheromosa's forward-facing view, Inspect Escape cleanup, removal of the model viewer on official-art selection, and Runerigus's initial official-art fallback. Other historical runtime models retain their previous evidence; this batch does not certify every one of those assets.
