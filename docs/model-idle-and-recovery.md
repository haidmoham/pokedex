Reproduce up to three source checks at a time:

```sh
npm ci --prefix scripts/model-pipeline
node scripts/model-pipeline/review-idle.mjs 149 150 909
blender -b -t 4 --python scripts/model-pipeline/render-idle-poses.py -- data/idle-review/150-decoded.glb data/idle-review/mewtwo 3.0166666507720947
```

The source-check command caps each response at 750,000 bytes and 30 seconds, verifies the existing SHA256 and size, and writes only ignored review copies. It does not alter admission or publish source binaries. Rendering uses the decoded equivalent and a fixed camera. These are offline renders, not sustained mobile playback evidence.
