# October 2 native-idle integration

The normal feed selects a pinned native HOME idle for every one of the 1,025 species. The user approved integrating the spot-reviewed whole catalog and merging it to main on October 2, with capable-browser WebGL checks to follow on their computers. This record describes source and build support; it does not claim every model's appearance is visually accepted.

## Inventory and selection

- The exact earlier public release remains separately pinned at 998 models, 547 native idles and 451 static models, with manifest SHA-256 `69264fdafa834db8dc0d946901971ac01b0f1a3ae1f7dc820f7bbc5c1076e4a4`.
- The integrated selection adds 478 genuine native HOME waits: replacements for 451 earlier static models and models for 27 earlier absent species. The resulting normal-feed inventory is 1,025 model selections and 1,025 native wait clips, with no static default selections.
- Original HOME source files, matching wait animations and all 16,991 selected material, texture and animation references were acquired and hash-checked at the exact revisions recorded in the source catalogs. The original metadata map remains a pinned upstream pointer; no extracted model or texture binary is committed to Git.
- Of the 478 new selections, 431 passed an offline baseline visual screen, 12 were uncertain and 35 had visual holds. The normal feed labels uncertain and held appearances and offers the earlier 3D model when one exists. A failed native load falls back to that earlier model, or official artwork for the 27 previously absent species. These visual statuses are not GPU acceptance.
- Five source-verified original-material variants were selected where offline review showed useful recovery: #990, #992, #993, #1006 and #1022. All other previously trusted native assets remain selected over optional corrected variants. #990 and #1022 use an explicitly disclosed Atlas-style layer approximation because the original proprietary shader equation is not recovered.
- Nine normal-feed assets are build-hosted: four exact lossless transfer repairs (#78, #851, #894 and #1008) and the five selected original-material scenes. Other new native models load on demand from immutable, SHA-256-pinned Atlas source URLs. #993 and #1022 alone use exact-hash transfer exceptions below 2 MB; decoded geometry and texture limits remain unchanged.

## Native motion and visual limitations

- #597's selected HOME wait is authentically stationary on visible geometry. It is a genuine source-authored idle; no attack, eye-state change or procedural animation is relabeled as motion.
- #868 and #1008 have source-authored visible loop seams. The integrated runtime retains the original curves rather than inventing smoothing.
- A separate stencil-capable Three canvas is used for the new HOME assets. Hash, byte, texture and decoded-memory limits are checked before scene mount; only the active species is loaded, with cancellation, pause, reduced-motion, panel and tab suspension, Inspect and disposal behavior. Effects that lack exact original shader equations are disclosed as approximations.
- Capable-browser WebGL/stencil appearance, physical-device performance and the remaining offline visual holds still need verification. The cloud browser used during development could not create WebGL. The `newlyVerifiedWorkingModels` field remains zero until those checks are completed; the 1,025 runtime count is a source-integrated selection count, not a claim of full visual acceptance.

## Rights and build boundary

The user authorized this integration and main merge. It does not establish redistribution rights for Pokémon models, textures or animation. Credits, source identities, transformations and unresolved-rights notices are retained in `/models/attribution.json` and the model details view. The Git repository stores metadata and converter code, not extracted binaries. A normal integrated build uses `POKEDEX_MODEL_RELEASE=2026-10-02-1025`; its prebuild fetches only immutable, identity-checked source inputs needed for the hosted derivatives. Other builds keep the previous release gate.
